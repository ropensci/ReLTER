# Construct full url for download

**\[stable\]** Construct full URL, including replacing year and month
where required.

## Usage

``` r
EDC_construct_full_url(edc_row, dataset_year, dataset_month)
```

## Arguments

- edc_row:

  `vector` one row for chosen dataset from edc_df.

- dataset_year:

  `string` Chosen year

- dataset_month:

  `string` Chosen month
