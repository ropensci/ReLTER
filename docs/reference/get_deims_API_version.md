# Get version of DEIMS-SDR API

**\[stable\]** This function obtains the version of the DEIMS-SDR API.

## Usage

``` r
get_deims_API_version(deims_url = get_deims_base_url())
```

## Arguments

- deims_url:

  A `character`. DEIMS-SDR base URL. Defaults to package settings.

## Value

version number.
